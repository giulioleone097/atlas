# Causal drilldown from result to repeatable practices

Analytical owner for public reverse and automatic learning. Return to the caller without writing rules or invoking learn/reverse. Preserve one evidence graph and practice set on the existing owner; reuse only nodes whose inputs, conditions and evidence still match.

1. Bind the achieved outcome, repository/workload, revision, time interval and decisive check. Declare the evidence boundary: supplied diff, profiles, benchmark/optimization ledger, review and linked work records actually read; name material missing sources. Preserve baseline/final KPI, units, noise, guards, setup and observed human/agent/compute/maintenance cost. Missing values stay unknown. Activity, PR status or fewer lines alone is not outcome proof; a preparation result proves only its verified property.
2. Start at the outcome and trace backward: which intermediate change explains it, which mechanism produced that change, which actual practice enabled the mechanism, and what made that practice effective? For each material strategy recursively ask why the intervention worked, why it was chosen over the available alternatives, and which constraints or enabling conditions made that choice effective. Follow those answers and their shared causes through evidence; finding a technique is not the end of the analysis. Give nodes stable IDs, input revisions, parents and source locators; shared prerequisites keep one identity. Each practice keeps the same ID and meaning in the graph, rule and integration receipt; never reuse it for another action. Distinguish implementation techniques from the practices that discovered, validated and integrated them. Preserve action order and what was knowable at each choice.
3. Challenge each material causal link: supporting/contrary observation, applicability, competing explanation and the smallest discriminating check. Compare evidenced rejected, neutral or unused alternatives, workload/setup changes, caches, hardware, noise and concurrent changes. Distinguish observation, supported inference and hypothesis. Before/after alone does not isolate cause. Keep inseparable changes as a bundle; never invent contribution percentages or sum overlapping gains. Proposed improvements belong to future validation, not the history of what caused this win.
4. A reproducible action is an intermediate node: continue into the causal reason its mechanism and prerequisites mattered. Close a branch only with an evidence-grounded causal relation suitable for abstraction, a shared already-resolved node, or an exact evidence gap and next probe. Record why further descent would no longer change attribution, applicability, action, safeguards or transfer. Do not stop at a familiar label, the first usable technique, an arbitrary depth/round count or desired response length. Do not manufacture deeper causes when sources end. Use existing controls/reverts/counterexamples first; scoped reads and permitted probes can resolve meaningful gaps. Real authority/resource limits yield partial coverage, never invented certainty.
5. Cover every material branch inside that boundary, including less prominent practices and enabling conditions; do not stop at the first or largest win. Give each a supported, conditional, contradicted or unresolved disposition with evidence. A missing branch remains visible while independent branches proceed. A limit means partial coverage, never "all practices found"; retain the exact continuation on this graph without resetting inherited budgets.
6. Build the smallest sufficient set of supported practices. Mark required, helpful, unsupported and context-dependent steps only where evidence distinguishes them; preserve necessary bundles, ordering and shared enablers once. Remove demonstrated redundant work without discarding other independent wins. Compare outcome and total cost while preserving correctness, safety and maintainability. A bundle win does not prove each part necessary or sufficient.
7. Check the reconstructed method forward: do its inputs and ordered practices explain the observed intermediate changes and final outcome, including failed/control cases? Resolve contradictions before declaring support; a coherent story is not a new measurement. For each practice, state a case where it should not apply. Transfer remains conditional until a real cross-context case or decisive falsification check supports it; repeated accounts of one event are one source.
8. Return every material practice with its ID, causal path, evidence, dependencies, resolved leaf/gap and ingredients for `playbook.md`: why the strategy worked, candidate causal relationship beyond its technical means, parameters, decision signals, checks and exceptions. Name its proposed point of use and next actual-use observation. Learn owns adoption; a generalized candidate method must still be delivered without claiming global validation. Distinguish historical practice from proposed adaptation and never invent savings/reuse counts.
9. Render nontrivial traces through `<plugin root>/skills/scope/references/composition.md`: an outcome overview with drilldown to mechanisms, practices, evidence and gaps using the same IDs. Use useful independent branch analysts under the caller's existing limits and reconcile dissent at their parent. This factual drilldown uses evidence links; optional actor simulation retains its own gate and bounds. Do not create another graph store or restart discovery at each handoff.

Return the graph, bounded coverage, complete practice set and unresolved frontier. `No reusable practice supported` requires an explicit evidence basis; it never hides unexamined material branches. Analysis alone performs no integration, new workflow or automatic experiment.
